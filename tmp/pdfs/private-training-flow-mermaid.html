Activity Diagram - Private Training และตารางงาน

Flow ตั้งแต่ลูกค้าเลือกโค้ช ส่งคำขอ อนุมัติ จัดสนาม ไปจนถึงการจัดการ Schedule

flowchart TD
    START([ลูกค้าต้องการจอง Private Training])

    START --> PKG{มีแพ็กเกจ Private<br/>ที่ยังใช้งานได้ไหม}
    PKG -- ไม่มี --> BUY[ซื้อแพ็กเกจก่อน]
    BUY --> PKG
    PKG -- มี --> COACH[เลือกโค้ช]

    COACH --> CAL[ดูตารางโค้ช<br/>แบบวัน / สัปดาห์ / เดือน]
    CAL --> DATE{วันที่ต้องการจอง<br/>เกิน 3 วันไหม}

    DATE -- เกิน --> DATELOCK[ดูตารางได้ตามปกติ<br/>แต่กดจองไม่ได้<br/>แจ้งว่าจองล่วงหน้าได้สูงสุด 3 วัน]
    DATELOCK --> CAL

    DATE -- ไม่เกิน --> SLOT{ช่วงเวลานี้โค้ชว่างไหม}
    SLOT -- ไม่ว่าง --> BUSY[แสดงช่วงเวลาสีเทา<br/>กดดูวันที่ เวลา และเหตุผลทั่วไปได้<br/>ไม่เปิดเผยข้อมูลลูกค้าคนอื่น]
    BUSY --> CAL

    SLOT -- ว่าง --> ASSIST{ต้องการผู้ช่วยสนามไหม}
    ASSIST -- ต้องการ --> FINDASSIST[ระบบกรองผู้ช่วยสนาม<br/>ที่ว่างตรงกับวันและเวลา]
    FINDASSIST --> ASSISTOK{มีผู้ช่วยว่างไหม}
    ASSISTOK -- ไม่มี --> CHANGE[เลือกเวลาใหม่<br/>หรือเลือกไม่ใช้ผู้ช่วย]
    CHANGE --> CAL
    ASSISTOK -- มี --> SELECTASSIST[เลือกผู้ช่วยสนาม]
    ASSIST -- ไม่ต้องการ --> SUBMIT
    SELECTASSIST --> SUBMIT[ส่งคำขอจอง]

    SUBMIT --> VALIDATE{ระบบตรวจสอบอีกครั้ง}
    VALIDATE -- ไม่ผ่าน --> ERROR[แจ้งสาเหตุ<br/>เช่น เวลาทับ ตารางไม่ว่าง<br/>แพ็กเกจหมด หรือเกิน 3 วัน]
    ERROR --> CAL

    VALIDATE -- ผ่าน --> USEPKG[ตัดจำนวนครั้งในแพ็กเกจ 1 ครั้ง]
    USEPKG --> PENDING[สร้างคำขอสถานะ<br/>รออนุมัติ]
    PENDING --> AUTOSCHEDULE[คำขอขึ้นในตารางงาน<br/>ของโค้ชและผู้ช่วยอัตโนมัติ]
    AUTOSCHEDULE --> NOTIADMIN[แจ้งเตือนแอดมิน<br/>กดแล้วไปหน้าจัดการ Private Training]

    NOTIADMIN --> DECISION{แอดมินตรวจสอบคำขอ}
    DECISION -- ปฏิเสธ --> REASON[กรอกเหตุผลปฏิเสธ]
    REASON --> REFUND[คืนจำนวนครั้งให้แพ็กเกจ]
    REFUND --> REJECTED[สถานะปฏิเสธ<br/>แจ้งเตือนลูกค้า]
    REJECTED --> END([จบรายการ])

    DECISION -- อนุมัติ --> AWAIT[สถานะรอจัดสนาม<br/>แจ้งเตือนลูกค้า]
    AWAIT --> COURTFILTER[ระบบกรองเฉพาะสนามที่ว่าง<br/>ตรงกับวันและเวลาของ Private]
    COURTFILTER --> COURTOK{มีสนามว่างไหม}

    COURTOK -- ไม่มี --> WAITCOURT[คงสถานะรอจัดสนาม<br/>แอดมินกลับมาจัดภายหลัง]
    WAITCOURT --> COURTFILTER

    COURTOK -- มี --> SELECTCOURT[แอดมินเลือกสนาม]
    SELECTCOURT --> RECHECK{ระบบล็อกข้อมูลและ<br/>ตรวจสนามซ้ำก่อนบันทึก}

    RECHECK -- สนามถูกใช้ไปแล้ว --> COURTERROR[แจ้งว่าสนามไม่ว่าง<br/>ให้เลือกสนามใหม่]
    COURTERROR --> COURTFILTER

    RECHECK -- สนามยังว่าง --> CONFIRMED[ยืนยัน Private Training]
    CONFIRMED --> BLOCKCOURT[ปิดใช้งานสนามตามช่วงเวลานั้น<br/>ป้องกันการจองสนามปกติและ Private ซ้ำ]
    BLOCKCOURT --> NOCHARGE[ไม่มีการคิดราคาสนาม<br/>และไม่หักเครดิตเพิ่ม]
    NOCHARGE --> NOTICUSTOMER[แจ้งลูกค้า โค้ช และผู้ช่วยสนาม<br/>พร้อมรายละเอียดวัน เวลา สนาม และสถานะ]
    NOTICUSTOMER --> FINISH([จองสำเร็จ])

    PENDING -. ลูกค้ายกเลิกก่อนเริ่ม .-> CANCEL
    AWAIT -. ลูกค้ายกเลิกก่อนเริ่ม .-> CANCEL
    CANCEL[ยกเลิกคำขอและคืนจำนวนครั้ง] --> END

    SCHEDULESTART([จัดการตารางงาน]) --> ROLE{ใครเป็นคนจัดการ}
    ROLE -- โค้ชหรือผู้ช่วยสนาม --> OWN[เพิ่ม ลบ แก้ไข<br/>ตารางงานของตัวเอง]
    ROLE -- Admin หรือ Super Admin --> ADMINEDIT[เพิ่ม ลบ แก้ไข<br/>ตารางโค้ชและผู้ช่วยสนาม]

    OWN --> EVENT[ระบุชื่อกิจกรรม วัน เวลา สี<br/>รายละเอียด และการเกิดซ้ำ]
    ADMINEDIT --> EVENT
    EVENT --> OVERLAP{เวลาทับกับตารางเดิม<br/>หรือ Private ที่ยืนยันแล้วไหม}
    OVERLAP -- ทับ --> EVENTERROR[ไม่ให้บันทึก<br/>แจ้งช่วงเวลาที่ชนกัน]
    EVENTERROR --> EVENT
    OVERLAP -- ไม่ทับ --> SAVEEVENT[บันทึกลงตารางงาน]
    SAVEEVENT --> UNAVAILABLE[ช่วงเวลาที่มี Schedule<br/>ถือว่าไม่ว่างสำหรับการจอง]
    UNAVAILABLE --> CAL
